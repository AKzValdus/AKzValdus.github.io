# AI Checkpoint RLBR

เว็บแบบประเมินภาษาไทยพร้อมใช้งานและเผยแพร่ผ่าน Supabase Edge Function

- เปิด URL สาธารณะเพื่อกรอกแบบประเมินจากเครื่องใดก็ได้
- ส่ง Reaction, Learning, Behavior และ Results เข้าฐานข้อมูลกลาง
- หน้า dashboard แสดงเฉพาะผลรวม ไม่มีการเปิดอ่านคำตอบรายคนแก่ผู้ใช้ทั่วไป
- คะแนนข้อเขียนอิสระไม่ถูกแสดงในแดชบอร์ด; ห้ามใส่ข้อมูลส่วนบุคคลหรือข้อมูลลับ
- ผลรวมคำนวณตามเกณฑ์บนเว็บและอัปเดตเมื่อกดโหลดผลรวมล่าสุด
- CSV/JSON ที่ดาวน์โหลดจากหน้าเว็บเป็นข้อมูลที่ส่งจากเบราว์เซอร์นั้นเท่านั้น
- Supabase publishable key อยู่ในเว็บได้; ห้ามใส่ service_role key ในไฟล์หน้าเว็บ
- โปรเจ็กต์อยู่บน Free plan; โปรเจ็กต์อาจหยุดชั่วคราวเมื่อไม่มีการใช้งาน และมีโควตาการใช้งาน
